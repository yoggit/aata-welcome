# Aata — the page that introduces it

The public landing page for **Aata**: the scoresheet for any card or board game, chowka bara
to play on a 5×5 or 7×7 board, and planning poker for a team.

- The page: **https://yoggit.github.io/aata-welcome/**
- The app itself: **https://aata.web.app**

One file, no build step, no dependencies. Push to `main` and GitHub Pages serves it.

It shares the family conventions: the theme choice is stored under `apps-theme`, so a visitor's
light/dark pick follows them across the sibling pages on this origin, and the palette is lifted
from the app's own tokens so the page matches the thing it advertises.
